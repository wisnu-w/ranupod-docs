## Mengapa Memilih RanuPod?

<CardGrid stagger>
	<Card title="Zero-Config Build Engine" icon="rocket">
		Cukup hubungkan repositori Git. Mesin build Railpack & Nixpacks otomatis mendeteksi dependensi (`package.json`, `go.mod`, `requirements.txt`, `composer.json`) dan membuat image OCI standar produksi dalam hitungan detik.
	</Card>
	<Card title="Isolasi Tingkat Hardware" icon="shield">
		Setiap proyek berjalan di dalam lingkungan private terisolasi (`rp-{projectID}-{stage}`) dengan proteksi jaringan zero-trust Cilium tanpa risiko kebocoran data antar pengguna.
	</Card>
	<Card title="Observabilitas Bawaan Tanpa Agen" icon="magnifier">
		Pantau log real-time (**[RanuLog](/observability/ranulog/)**), pelacakan latensi antar-layanan (**[RanuTrace](/observability/ranutrace/)**), hingga skor Web Vitals browser (**[RanuRUM](/observability/ranurum/)**) tanpa biaya instalasi pihak ketiga.
	</Card>
	<Card title="Transparan dalam Rupiah (IDR)" icon="seti:salesforce">
		Harga transparan dalam mata uang Rupiah tanpa risiko fluktuasi kurs. Tersedia **Free Tier selamanya**, paket bulanan terprediksi, dan **Pay-As-You-Go per detik presisi**.
	</Card>
</CardGrid>

## Panduan Cepat Berdasarkan Kebutuhan

### 1. Pahami Konsep & Arsitektur
- [Hirarki Proyek, Service & Stage](/concepts/projects-services-environments/): Pahami relasi Tenant, Project, Blueprint Service, dan K3s Namespace.
- [Arsitektur Sistem & Build Engine](/concepts/architecture/): Cara kerja Control Plane, Redis Asynq, BuildKit Worker, dan Operator K3s.
- [Siklus Deployment & Rollback Instan](/guides/deployments-and-rollbacks/): Bagaimana status `superseded` menghemat biaya dan cara rollback sub-detik.

### 2. Pilih Runtime Bahasa Anda
- [Node.js & Next.js](/frameworks/nodejs/): Standalone mode, Express, NestJS, dan pnpm/bun support.
- [Go (Golang)](/frameworks/golang/): Kompilasi statis berkecepatan tinggi dengan Chi, Fiber, atau Gin.
- [Python & FastAPI](/frameworks/python/): FastAPI, Django, Flask dengan Gunicorn & Uvicorn.
- [PHP & Laravel](/frameworks/php/): Laravel modern dengan Nginx, PHP-FPM, dan persistent storage.
- [Custom Dockerfile](/frameworks/dockerfile/): Multi-stage builds, non-root security, dan BuildKit caching.

### 3. Template Siap Pakai (1-Klik)
- [Katalog Template](/guides/templates/): Luncurkan database PostgreSQL, Redis, n8n automation, Evolution API WhatsApp, atau MinIO Object Storage dengan sekali klik.

### 4. Konfigurasi Produksi
- [Environment Variables & Secretbox](/guides/environment-variables/): Enkripsi AES-256-GCM at-rest dan pemisahan env frontend vs backend.
- [Custom Domain & Auto-SSL](/guides/custom-domains/): Sambungkan domain kustom Anda dengan sertifikat Let's Encrypt otomatis.
- [Persistent Storage (NVMe)](/guides/persistent-storage/): Volume penyimpanan permanen berkecepatan tinggi tahan restart.
- [Alokasi Sumber Daya & HPA](/guides/scaling/): Atur limit vCPU/RAM dan Horizontal Auto-Scaling saat lonjakan traffic.
