## Alur Singkat Deployment

1. **Buat Proyek**: Buat kelompok aplikasi baru di [Console Dashboard](https://console-dev.ranuoutdoor.id).
2. **Koneksikan Repositori**: Pilih repositori GitHub publik atau privat yang ingin Anda jalankan.
3. **Konfigurasi Lingkungan**: Masukkan variabel lingkungan seperti database URL atau secret API key.
4. **Deploy & Akses**: Dalam waktu kurang dari 60 detik, aplikasi Anda aktif dengan URL HTTPS gratis (`*.ranupod.app`) atau domain kustom Anda sendiri.
